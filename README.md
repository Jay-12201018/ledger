# 个人账本

一个人用的记账本。记每天的开销，看周报和月报，设预算和存钱目标。数据只存在这台手机里，没有账号，也不会上传。

发布地址：<https://jay-12201018.github.io/ledger/>

## 开启 GitHub Pages

1. 打开这个仓库的 **Settings**
2. 左侧进入 **Pages**
3. 在 **Build and deployment** 里，Source 选择 **Deploy from a branch**
4. Branch 选择 **main**，文件夹选择 **/ (root)**
5. 保存。等一两分钟后，用 Safari 打开上面的地址

文件都在仓库根目录，并且使用相对路径，所以页面会正确出现在 `/ledger/` 下面。

## 添加到 iPhone 主屏幕

请用 **Safari** 打开，不要用微信里的浏览器。

1. 打开 <https://jay-12201018.github.io/ledger/>
2. 点底部分享按钮（方框加上箭头）
3. 往下划，点 **添加到主屏幕**
4. 名称会显示为「个人账本」，点右上角 **添加**
5. 之后从主屏幕的图标打开。它会占满屏幕，像一个独立的 App，没网也能记

第一次打开需要联网。装好之后，账单和页面都留在这台手机上。以后如果有更新，重新打开一次就会换上新版本。

## 可以做什么

- **记一笔**：底部中间的加号。可选支出或收入、分类、日期、备注，以及微信 / 支付宝 / 现金 / 银行卡。金额用自己的数字键盘，可以加减。点已经记下的一笔，可以修改或删除。
- **明细**：看这个月花了多少、收入、预算还剩多少，账单按天分组。
- **报表**：按周（周一到周日）或按月看支出、收入、分类占比和排行。点某个分类，看这段时间里的账单。
- **预算**：每月总预算，也可以按分类再设一档。用到 80% 或超支时，明细和预算页都会提醒。另外可以设一个存钱目标，并往里面存钱。
- **分类管理**：在「我的」里。可以新增、改名、换颜色和图标、拖动排序。如果删掉的分类下面还有账单，会先问你要不要挪到「其他」。
- **账单导入**：读取微信或支付宝导出的 csv / xlsx。邮件里的压缩包要先用密码解压，再选择里面的文件。预览里会标出重复、退款、转账和不计收支，点确认之后才会写入。
- **备份**：在「我的」里导出一份 JSON。换手机时再用「恢复备份」导回来。iPhone 上会调用系统分享；如果没有弹出分享，页面里还有一个保存链接。

第一版不包含自动识别记账，也没有账号和云同步。

## 本地预览

页面是按 `/ledger/` 这个子路径来写的。请在仓库的**上一级目录**启动静态服务器：

```bash
cd ..
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/ledger/>。如果当前文件夹的名字就是 `ledger`，在它的父目录里启动即可。

## 测试

```bash
node --test tests/*.test.js
```

`samples/` 里有微信支付的 csv、xlsx，以及支付宝 GBK 编码的 csv。解析器的测试读的就是这些文件。需要重新生成时：

```bash
node tests/gen-samples.mjs
```
